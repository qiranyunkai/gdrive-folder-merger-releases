# GDrive 整合 · macOS 下载与更新

将 Google Drive 分批下载得到的 ZIP、文件夹和普通文件整合到一个新项目目录，保留层级、源文件及冲突副本。本仓库仅发布安装包、版本信息和签名更新清单，源码仓库保持私有。

## 下载与安装

[下载最新版本](https://github.com/qiranyunkai/gdrive-folder-merger-releases/releases/latest)

当前为 **0.1.2（构建 3）未公证测试版**，适用于 Apple 芯片 Mac，最低 macOS 13。下载 `GDriveFolderMerger-0.1.2-3-arm64.zip`，解压并将 `GDrive Folder Merger.app` 拖入“应用程序”。不要下载 GitHub 自动生成的 Source code 归档，它不是安装包。

更新包已使用 EdDSA 签名；应用暂未使用 Apple Developer ID 签名或通过 Apple 公证，首次打开可能需要通过 macOS 的“隐私与安全性”允许运行。

## 联网更新

应用菜单提供“检查更新…”，设置中可开启自动检查。版本清单和安装包可匿名下载，无需 GitHub 登录。文件整合在本机完成，更新不会上传项目文件或任务报告；处理文件时不会安装更新或退出。

0.1.1 及更早的原发行包没有内置更新地址，需手动安装 0.1.2 一次，之后可使用软件内更新。

## 本版改动

- 文件列表支持多项勾选、全选和批量移除，原文件保留。
- 支持普通文件、独立 ZIP 和文件夹混合导入；ZIP 解压，其他文件原样复制。
- 修复部分磁盘首次整合时的 `Operation not supported` 提交错误，兼容写入仍不覆盖已有文件并进行校验。
- 加入签名联网更新与任务保护。

本版通过自动化测试和本机界面验收。真实外置盘、网络卷及其他系统版本仍需复验；特殊卷的兼容复制在突然断电或进程退出时可能留下未完成文件，请以任务报告为准。
